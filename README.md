# Week 1 Day 3 Homework – Food Blog with Pug include & components

The static `index.html` food blog page converted to an Express app rendered with Pug.

- `views/content.pug` – the page, built from components with `include`
- `views/includes/` – `head`, `header`, `photos`, `footer`, and `post` (a mixin used for each comment)
- `data/posts.json` – the comment data rendered by the `post` component
- `public/` – `styles.css` and `images/` served as static files

Run: `npm install` then `npm start`, and open http://localhost:3000
